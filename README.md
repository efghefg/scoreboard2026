# FINAL Scoreboard

Static GitHub Pages version of the FINAL scoreboard. Animation shows 10–12 points; the final reveal adds the remaining 1–9 points.

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. In **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/root`.
6. Save and wait for the published `github.io` link.

This version is a static HTML/CSS/JS site. It does not need Jupyter, Python, ipywidgets, or matplotlib.
